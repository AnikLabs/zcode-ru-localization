## [1.0.8] — 2026-11-04 — тёмный интерфейс + обновления через AutoUpdater.NET
### Changed
- Интерфейс установщика переведён на библиотеку [ReaLTaiizor](https://github.com/Taiizor/ReaLTaiizor)
  (Apache-2.0): тёмная Material-тема, Material-кнопки и поля; указан разработчик (AnikBeris, ссылка на профиль).
- Проверка обновлений переведена на библиотеку [AutoUpdater.NET](https://github.com/ravibpatel/AutoUpdater.NET)
  1.9.3 (MIT): фид `releases/latest/download/update.xml` (ассет каждого релиза), русский диалог обновления,
  changelog в WebView2, SHA-256-контроль zip по `<checksum>`.
### Added
- В комплект включены библиотеки: ReaLTaiizor.dll, AutoUpdater.NET.dll (+ru-сателлит),
  Microsoft.Web.WebView2 (Core/WinForms/WebView2Loader); к каждому релизу прилагается update.xml.
### Fixed
- Кнопка выбора папки переименована в «Директория» и перенесена влево от поля пути.

## [1.0.7] — 2026-11-03 — установщик с проверкой обновлений
### Added
- Установщик (РусификаторZCode.exe): секция «Обновление» — сверка с GitHub Releases
  (api.github.com/repos/AnikLabs/zcode-ru-localization/releases/latest) при запуске и по кнопке;
  при наличии новой версии — кнопка «Скачать vX.Y.Z»: скачивание релизного zip с прогрессом,
  проверка SHA-256 по checksums.txt, распаковка, запуск новой версии установщика (самообновление).
- Необязательный аргумент командной строки: путь к папке ZCode (пресет для стендовых тестов).
### Fixed
- Потокобезопасные LogLine/SetStage (фоновые операции больше не падают при обращении к UI).
### Changed
- Build.bat: + ссылки System.IO.Compression(.FileSystem).dll.

## [1.0.5] — 2026-10-24 (опубликован: [release v1.0.5](https://github.com/AnikLabs/zcode-ru-localization/releases/tag/v1.0.5))
### Fixed
- Критический баг: после отката русификатора и повторной установки приложение оставалось на СТАРОЙ версии ZCode. Причины исправлены: (1) откат восстанавливал `app.asar.orig` не проверяя версию — теперь откат перебирает бэкапы (`.orig`/`.bak`/`.original`) и восстанавливает только совпадающий с версией `ZCode.exe`, а при отсутствии такого отказывается откатывать с понятным сообщением; (2) установка не проверяла версию содержимого `resources\app` и оставляла устаревший каталог, который затенял свежий `app.asar` — теперь перед копированием старый каталог удаляется целиком, а версия пропатченного стейджа сверяется с версией `ZCode.exe`; (3) источник установки (`app.asar`) выбирается по совпадению версии (`app.asar` → `.orig` → `.bak` → `.original`).
- Три рантайм-бага `install-ru.ps1`: неопределённые `$res`/`$asar`; массив кандидатов склеивался в один вызов `Join-Path` (запятые на концах строк); вызов несуществующей функции `Read-VersionFromPackageJson`.
- GUI-установщик: убрана C#6-интерполяция строк (не компилировалась штатным `csc` .NET Framework 4).
### Changed
- `ru.json` под каталог ZCode 3.16.3: 6999 ключей (было 6989): +15 новых строк (remote-ошибки, ссылки входа OAuth, копирование MID устройства), −5 устаревших.
### Verified
- На стенде-копии живой машины (asar 3.16.3 + устаревший русский app-каталог 3.16.2 + старые бэкапы 3.14.x): установка v1.0.5 → состояние вылечено, «Русификация ZCode 3.16.3.8992 установлена»; запуск — полный русский UI 3.16.3, английский fallback 0; скриншот `Screenshots/v1.0.5/launch-01-main-3.16.3.png`.

## [1.0.3] — 2026-09-23 (опубликован: [release v1.0.3](https://github.com/AnikLabs/zcode-ru-localization/releases/tag/v1.0.3), коммит bd31294)
### Fixed
- Критический баг: после установки на ZCode 3.14 приложение не запускалось — окно ошибки
  `(0, h.jsx) is not a function`. Причина: в `patch.mjs` интероп-вызов jsx-runtime был
  зашит как `h=n()` (имя из сборки 3.12.3); в 3.14 бандлер переименовал биндинг в `r`.
  Теперь интероп берётся из найденного якоря — установщик снова совместим с любыми
  переименованиями биндингов в будущих версиях.
### Changed
- `ru.json` обновлён под ZCode 3.14: 6129 ключей = en-US (1:1). Переведены 1215 новых
  строк (workflows-хаб, менеджер ресурсов, горячие клавиши, шаринг диалогов, провайдеры
  моделей, онбординг), удалены 107 устаревших.
- Артефакты: `Build/v1.0.3/` (zip + exe + checksums).
### Verified
- На тестовом стенде (копия 3.14): установка → запуск → полный русский UI, включая новые
  настройки 3.14. Скриншоты: `Screenshots/v1.0.2/stand-patched/`.
